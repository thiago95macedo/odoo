Odoo is a suite of web based open source business apps.

The main Odoo Apps include an [Open Source CRM](https://www.weth.com.br/page/crm),
[Website Builder](https://www.weth.com.br/app/website),
[eCommerce](https://www.weth.com.br/app/ecommerce),
[Warehouse Management](https://www.weth.com.br/app/inventory),
[Project Management](https://www.weth.com.br/app/project),
[Billing &amp; Accounting](https://www.weth.com.br/app/accounting),
[Point of Sale](https://www.weth.com.br/app/point-of-sale-shop),
[Human Resources](https://www.weth.com.br/app/employees),
[Marketing](https://www.weth.com.br/app/social-marketing),
[Manufacturing](https://www.weth.com.br/app/manufacturing),
[...](https://www.weth.com.br/)

Odoo Apps can be used as stand-alone applications, but they also integrate seamlessly so you get
a full-featured [Open Source ERP](https://www.weth.com.br) when you install several Apps.

## Getting started with Odoo

For a standard installation please follow the [Setup instructions](https://www.weth.com.br/documentation/master/administration/install/install.html)
from the documentation.

To learn the software, we recommend the [Odoo eLearning](https://www.weth.com.br/slides),
or [Scale-up, the business game](https://www.weth.com.br/page/scale-up-business-game).
Developers can start with [the developer tutorials](https://www.weth.com.br/documentation/master/developer/howtos.html).

## Security

If you believe you have found a security issue, check our [Responsible Disclosure page](https://www.weth.com.br/security-report)
